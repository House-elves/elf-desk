# House Elves brand: "Done by morning"

Like the elves in the shoemaker's tale, the work happens overnight and is waiting, finished, in the morning. The mark is a checkmark whose long stroke ends in an elf's hat with a bobble: "done" and "elf" at once, and clear at 16 px.

| File | Use |
|---|---|
| `mark.svg` | The mark on a light background (READMEs, docs) |
| `mark-tile.svg`, `mark-tile-256.png` | The mark on a moss tile (app icons) |
| `avatar.svg`, `avatar.png` | 500×500 square for the GitHub org avatar (GitHub rounds the corners) |

## Colours

| Name | Hex | Use |
|---|---|---|
| Moss | `#24533F` | The one accent: logo tile, primary buttons, links |
| Fern | `#7DB68A` | Moss's stand-in on dark backgrounds |
| Bobble | `#F0C33C` | The hat's bobble, nothing else |
| Paper | `#F4F6F1` | Page background, the mark on moss |
| Ink | `#17201B` | Text |

Green, amber and red stay reserved for state (CI passing, waiting, failing).

## Type

- Bricolage Grotesque (700–800) for names and page headings.
- IBM Plex Sans for everything else.

Keep the folk-tale elves: no socks, pillowcases or other Harry Potter house-elf imagery.
